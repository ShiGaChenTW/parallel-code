# docs/

產品與架構文件。工作紀錄（每一波的決策理由）在 [`plans/`](../plans/README.md)。

## ⚠️ 加檔案前先看這裡

`.gitignore` 對這個目錄用的是**逐檔允許清單**（`docs/*` 全忽略，再逐個 `!` 放行）。
新增或改名任何 `docs/` 底下的檔案，**同一個 commit 裡必須加對應的 `!` 規則**，
否則檔案不會進版控，而 `git status` 完全不會提醒你 —— 它對被忽略的路徑保持沉默。

```bash
git check-ignore -v docs/<檔名>   # 有輸出且規則不以 ! 開頭 = 這個檔案不在版控裡
```

子目錄無法逐檔放行：`docs/*` 排除的是目錄本身，git 不會走進被排除的目錄。
`docs/archive/` 這種要先 `!docs/archive/` 才談得上裡面的規則。
**這也是波次文檔歸檔在 `plans/` 而不是 `docs/` 的原因** —— `plans/` 沒有這層清單。
